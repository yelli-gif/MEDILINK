# Medilink Lot 5 - Suivi Pharmacie & Calendrier

Ce module gère le suivi des prises de médicaments et la génération du calendrier patient.

## Lancement
1. Vérifier la connexion au serveur MySQL Railway (configuré dans `application.properties`).
2. Lancer l'application via `MedilinkLot5Application.java`.
3. Le serveur démarre sur le port `8085`.

## Tests
* Une collection Postman est disponible dans le dossier `postman/` ou sur le Trello.
* Les données sont actuellement simulées via `fake_ordonnance.json`.

## Acces
