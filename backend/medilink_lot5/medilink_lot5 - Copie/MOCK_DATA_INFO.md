# Structure des Données Simulées (Mocks)

Les données sont chargées depuis `src/main/resources/data/fake_ordonnance.json`.

### Structure de l'Ordonnance Mockée :
- **patientId** : Identifiant unique du patient.
- **lignes** : Liste d'objets contenant le nom du médicament, l'heure de prise (ISO 8601) et le statut initial ("A_PRENDRE").
